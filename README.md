# Система охранных услуг

Консольное приложение на Java для управления заявками на охранные услуги. 

## Описание

Программа позволяет вести учёт клиентов охранного агентства и их заявок на услуги охраны. 
Все данные хранятся в базе данных PostgreSQL. Работа с системой осуществляется через 
интерактивное консольное меню.

## Возможности

- **Управление клиентами:** добавление и просмотр клиентов.
- **Управление заявками:** создание, просмотр, поиск, изменение статуса, удаление.
- **Поиск и фильтрация:** по адресу объекта и по статусу заявки.
- **Сортировка:** по ID и по дате создания.
- **Статистика:** 5 показателей по всем заявкам.
- **Экспорт данных:** в файл CSV.

## Технологии

- Java 17
- PostgreSQL 14+
- JDBC (PostgreSQL JDBC Driver 42.7.1)
- Maven (для управления зависимостями)

## Требования перед запуском

1. **Java 17** или выше
